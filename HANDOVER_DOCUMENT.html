8. Maintenance & Operator Update Guide

  • How to Edit Safari Packages or Prices: Open src/data/safaris.ts and update prices, durations, or itinerary days.
  • How to Edit National Park Information: Open src/data/destinations.ts.
  • How to Add a New Blog Post: Add a new .md file into src/content/blog/ with title and frontmatter.
  • How to Build & Deploy Updates to Cloudflare:
    1. Run: npm run build (compiles static site into ./dist)
    2. Run: npx wrangler deploy (publishes to blisspathtours.com in ~15 seconds)
